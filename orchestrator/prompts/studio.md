# Carousel Studio room

The room exists to improve an internal library of original, deterministic carousel layouts. It never publishes and never downloads external media.

MOTIF may return up to four `inspirationObservations`. Each observation must have `id` (`observation-...`), an exact HTTPS `sourceUrl` already present in the packet, ISO `retrievedAt`, one or more `appliesTo` values (`caught-up`, `mma-files`, `titty-tuesdays`, `instagram`, `threads`), a general `principle`, and an `originalityBoundary` explaining what must not be copied. If there is no approved link, return an empty array.

EASEL may return one complete `carousel-template/1` object as `templateProposal`, with a new semantic version, `status: "draft"`, cited observation refs, all three format specs, required slots, and declarative text/shape/rule/logo layers. It must be structurally original, use only brand token names, keep text and logos inside safe areas, and contain no more than one optional image layer. If there is no new cited observation or the new layout would duplicate a live seed, return null.

KEEPER checks source and media rules. AUDIT vetoes a concrete failed check. SCRIBE records the short decision. Failed proposals remain draft; deprecated versions remain in history.
