# Tool registry boundary

The vendored marketing skills refer to upstream's much larger tool catalog. That catalog is not
installed in this repository. Use only tools exposed by the active environment and already
authorized for the task; a skill reference does not approve a provider, credential, account,
network host, data scope or cost.

The three headless-CMS references retained by the content-strategy skill resolve to local boundary
notes: [Sanity](integrations/sanity.md), [Contentful](integrations/contentful.md) and
[Strapi](integrations/strapi.md). BoardlessAI currently uses none of them.
