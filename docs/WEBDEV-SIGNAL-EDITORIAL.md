# WebDev Signal evidence-to-copy boundary

The accepted `webdev-evidence-brief/1` is the only editorial truth input. It is built after #440
selection and carries the selected record, selection and input hashes, source-backed claims,
affected/fixed scope, stability, uncertainty, safe actions, official source and invalidation rules.
It has no locale flourish, model output, renderer, credential or publishing authority.

The default editor is deterministic and produces independent Czech and English drafts for
Instagram and Threads. Both packages declare every claim, version, audience and action used. A
shared validator checks the brief hash, required claim parity, unsupported facts, exact security or
preview language, source attribution, source-copy overlap, literal cross-locale cloning, hype,
recent duplication and platform-neutral limits supplied by Social Distribution. A locale-local
schema or length failure may hold that locale without changing the brief or broadening the other.

`WEBDEV_SIGNAL_EDITOR` is the sole optional model role. The configured `gpt-5.6-luna` 4000/1500
route is used only when a caller explicitly selects the model strategy and independent founding,
budget and provider authority all pass. One reservation plus one bounded repair fit below the
selected-day `$0.03` ceiling at the dated repository price. Malformed output records actual cost;
only accepted structured packages enter the cache. Raw provider output is never persisted.

`NO_EDITION`, a missing brief, an unchanged accepted cache key, unavailable authority, missing
route/provider or refused reservation makes zero calls. Package state remains `draft` or `held`;
Design Lab rendering belongs to #442 and Social Distribution approval, connection, queue and
publishing belong to #443.
