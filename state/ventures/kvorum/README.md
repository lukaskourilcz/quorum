# Kvórum state

This directory holds Kvórum's approved configuration and durable records. Record
directories are created lazily only when there is real content to keep; empty
scaffolding is not committed.

Kvórum is drafts-only. It has no public account, publishing channel, credential or
publisher route, and this workspace does not authorize creating or touching any of
them. The public name and 21:00 Prague desk hour remain provisional owner choices.

External sourcing remains fixture-only and costs `$0` while `KV-APIFY-001`,
`KV-SOURCES-002`, `KV-ACCOUNTS-003`, `KV-EDITORIAL-004`, the parent Apify approval
and a countersigned daily-budget reallocation are missing. A dry result is evidence
that the implementation works, not permission to fetch, spend, publish or claim that
the venture has launched.
