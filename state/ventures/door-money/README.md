# Door Money state

This public directory stores review-only Door Money drafts, bounded derivative records and
owner-entered outcomes. Nothing here is published, scheduled or sent by the system. Every
external action remains the owner's decision and work.

The manuscript, full-text chunks and embeddings never belong in this repository. The private
store is the owner-created source repository identified by **BOOK-SOURCE-001** (working pointer:
`lukaskourilcz/rapovej-denik-source`). The shipped runtime never clones that repository and never
receives `BOOK_SOURCE_TOKEN`; the optional repository-scoped, contents-only token belongs only to
an owner-run checkout outside this public tree. Local ingestion reads an explicit ignored path,
including `state/ventures/door-money/manuscript/` when the owner chooses it.

Committed excerpts are derivatives capped at 600 characters. Style-profile exemplars are capped
at 40 entries of 280 characters each. Until the private-source and ingestion approvals are
countersigned, the desk stays on fixture-backed dry paths and records that it held at $0.

Public state is limited to bounded knowledge pointers and derivatives, daily recommendations,
Thursday action packets, owner completions/results, playbooks and the replayable
`performance-weights.json`. Every artifact has a strict contract and a single writer. Missing or
malformed knowledge fails closed before a paid call; no fixture contains real book text.
