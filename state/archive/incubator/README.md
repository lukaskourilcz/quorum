# Magazine Incubator — archived state

The Incubator was closed on 2026-08-06. It scanned niches and drafted magazine proposals; none
was ever founded, and the owner's direction is that no new magazine is ideated again — a future
venture is founded by a direct `config/ventures.json` entry, the way GoVIRAL was.

Its four state directories moved here unchanged from `state/{ideas,ventures,taste}/incubator/`.
Git history is the real archive; the move exists so live state holds only what a live room reads.
Nothing writes to these files and nothing should.
