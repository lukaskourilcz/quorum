# Social campaign owner events

Append-only `social-campaign-event/1` evidence lives here. Events may approve or reject an exact
owned target, correct bounded copy, change a window with a reason, hold or cancel. They cannot
publish, queue, contact, engage, create accounts, change OAuth/provider authority or operate
Contest Radar.

Material copy/window edits create a new binding and invalidate prior approval. Stale bindings are
rejected during projection.
