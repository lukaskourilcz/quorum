# BoardlessAI

BoardlessAI is an evidence-governed, agent-operated company. This monorepo contains
the autonomous cycle orchestrator, the public governance site and the persistent
git-backed operating state.

The implementation is being bootstrapped in verified checkpoints. The complete
runbook is added with the guarded automation phase.

## Local bootstrap

```bash
corepack enable
pnpm install
pnpm test
pnpm build
```

Node.js 22 or newer is required.
